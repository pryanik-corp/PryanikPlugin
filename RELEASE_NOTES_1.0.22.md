# PryanikPlugin 1.0.22

## Changes

- CSRV can use `/gm 0`, `/gm 1`, and `/gm 2` in any world, including the lobby.
- Other ranks keep the existing restrictions: ADMIN+ can use permitted modes in game worlds; spectator remains CSRV-only.
- Combat lock still prevents changing game mode.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
