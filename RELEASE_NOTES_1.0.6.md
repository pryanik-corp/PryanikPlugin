# PryanikPlugin 1.0.6

## Changes

- Add CSRV `/portal`: while standing inside a Nether or End portal, open a GUI to assign a supported player command to that specific portal block, or remove its assignment.
- Run the configured action for authenticated players when they enter the assigned portal. Assignments persist in PostgreSQL and work in the lobby and other worlds.

## Compatibility

- Minecraft 1.20.4
- Paper
- Java 17
- PostgreSQL, WorldEdit, and WorldGuard required.
