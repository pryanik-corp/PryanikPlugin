# PryanikPlugin 1.0.10

## Changes

- New griefs include an independent normal-world Spawn dimension alongside Overworld, Nether, and End.
- `/gm` access is restricted to ADMIN and higher, with CSRV allowed to use `/gm 1` in the lobby.

## Compatibility

- Minecraft 1.20.4
- Paper, Java 17
- PostgreSQL, WorldEdit, WorldGuard
