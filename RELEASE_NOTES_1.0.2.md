# PryanikPlugin 1.0.2

## Changes

- Refresh player visibility after authentication, joining, and changing worlds; retain Vanish and per-world visibility rules.
- Include all registered clan members in newly created clan regions and set the region priority to support nested protection regions.
- Add a PostgreSQL viewer for listing personal homes, including their owner, world, and coordinates.
- Provide bilingual English/Russian Modrinth project description.
- Update project and plugin metadata to version 1.0.2.

## Compatibility

- Minecraft 1.20.4
- Paper
- Java 17
- PostgreSQL, WorldEdit, and WorldGuard required.
