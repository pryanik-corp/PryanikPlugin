# PryanikPlugin 1.0.25

## Changes

- Add `/villager` for CSRV (also server operators): choose an action in a UI and spawn a named, persistent, invulnerable toolsmith villager; clicking it runs that action.
- Supported villager/portal actions: `mode`, `lobby`, `kit_start`, `home`, `chome`, `rtp`.
- Add `/rtp`: random safe surface location at least 1,000 blocks from the current position, within 10,000 blocks. From a grief Spawn world, it targets that grief's normal Overworld at random coordinates.
- Add `/rtp` to the `/portal` action menu.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
