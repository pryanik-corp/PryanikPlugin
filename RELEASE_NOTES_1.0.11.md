# PryanikPlugin 1.0.11

## Changes

- Players now enter each grief through its `<grief>_spawn` central world; respawning from a grief returns to that central world.
- Spawn is a protected Adventure safe area: no block place/break/interactions, personal/clan claims or homes, PvP, hostile creature spawning, weather, or damage.
- PvP toggles for a grief do not enable PvP in its protected Spawn world.
- The Spawn and game dimensions still share the grief inventory/state scope.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
- PostgreSQL, WorldEdit, and WorldGuard required.
