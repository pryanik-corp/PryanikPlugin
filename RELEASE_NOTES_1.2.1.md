# PryanikPlugin 1.2.1 — Paper 26.3

- `/portal` opens the existing command menu anywhere; it no longer requires the player to stand next to a frame.
- Choosing an action gives a one-use, named flint-and-steel bound only to that action, not to a location.
- Use it on any complete supported obsidian frame to light it and assign the chosen command, or on an existing portal block to change its command. The barrier option gives a one-use removal flint for an existing portal.
- Uses Paper 26.3 API, Java 25, WorldEdit 7.4.6 and WorldGuard 7.0.20.
