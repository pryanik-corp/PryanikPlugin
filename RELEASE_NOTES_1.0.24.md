# PryanikPlugin 1.0.24

## Changes

- `/portal` now searches a larger area for a valid unlit obsidian frame.
- Supports rectangular frames up to 64 blocks wide and 64 blocks high rather than stopping at the vanilla 21-block limit.
- Ordinary lit portals continue to be detected and configured as before.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
