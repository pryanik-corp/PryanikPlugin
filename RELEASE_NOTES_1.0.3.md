# PryanikPlugin 1.0.3

## Changes

- Make clan regions created through `/privat` behave like standard personal regions, while automatically adding all current clan members as region members.
- Add a clan GUI for leaders to inspect and delete their clan regions.
- Add a clan-member GUI for leaders to remove members; removed members are removed from the clan regions as well.
- Add `/clan kick <nickname>` and automatically sync clan membership with clan regions when a member joins or leaves.

## Compatibility

- Minecraft 1.20.4
- Paper
- Java 17
- PostgreSQL, WorldEdit, and WorldGuard required.
