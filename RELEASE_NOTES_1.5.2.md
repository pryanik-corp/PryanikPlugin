# PryanikPlugin 1.5.2 — Paper 26.3

- Website world controls now include a per-world game mode: Survival, Creative, Adventure or Spectator.
- Selected mode is applied to players when they enter/change into a configured world and is enforced in lobby and managed spawn worlds.
- Lobby/spawn default to Adventure; site can configure their required mode too. API setting allowlist remains strict; no console commands or RCON.
