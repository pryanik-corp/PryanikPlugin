# PryanikPlugin 1.0.27

## Fixes

- Allow the plugin-created `/villager` toolsmith NPC to spawn in protected grief Spawn worlds while continuing to block other creature spawns there.
- Expand `/portal` search for an existing portal and associate the configured action with every block in the connected portal surface, so standing anywhere inside a large portal triggers it. Removing the action clears all connected portal blocks.
- Large unlit obsidian frames remain supported up to 64 by 64 blocks.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
