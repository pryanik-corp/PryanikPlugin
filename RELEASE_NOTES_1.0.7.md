# PryanikPlugin 1.0.7

## Changes

- `/portal` can now ignite a nearby complete obsidian Nether portal frame when no active portal exists, then open the portal command selection menu.
- Incomplete, obstructed, or ambiguous nearby frames are left unchanged.
- Portal command assignments continue to persist in PostgreSQL.

## Compatibility

- Minecraft 1.20.4
- Paper
- Java 17
- PostgreSQL, WorldEdit, and WorldGuard required.
