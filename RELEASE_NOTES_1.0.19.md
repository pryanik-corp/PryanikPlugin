# PryanikPlugin 1.0.19

## Changes

- On a configured portal, first teleport the player to a safe block beside the portal.
- Open the configured UI/action on the following server tick, after the exit teleport has completed.
- Keep the player temporarily invulnerable across the teleport/UI handoff, then restore their previous invulnerability state.

## Compatibility

- Minecraft 1.20.4; Paper; Java 17
